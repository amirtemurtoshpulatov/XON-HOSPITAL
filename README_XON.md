# XON HOSPITAL

Многоязычный сайт клиники на Next.js, TypeScript, Payload CMS и PostgreSQL.

## Что уже работает

- языки: русский, узбекский, английский, казахский, таджикский;
- адаптивная главная с фирменной анимацией;
- CMS `/admin` для главной страницы, палитры, врачей, направлений, цен, страниц, медиа и SEO;
- видео в разделах сайта и в профилях врачей: ссылки Reels, YouTube и Vimeo или загрузка файлов.
- заявки с валидацией, согласием, UTM-метками и статусами CRM;
- синхронизация заявок с Google Sheets через webhook;
- production Dockerfile и PostgreSQL-конфигурация.

## Локальный запуск

Требования: Node.js 22.23.4+ и pnpm 11.

```bash
pnpm install
pnpm dev
```

Откройте:

- сайт: `http://localhost:3000/ru`
- админка: `http://localhost:3000/admin`

Локально используется SQLite. В production задайте PostgreSQL через `DATABASE_URL`.

## Как добавить видео

- **В раздел сайта:** в админке откройте «Клиника → Видео на сайте», создайте запись и выберите «Где показать». Для отдельной страницы скопируйте её путь без языка, например `services/check-up`. Включите «Показать посетителям».
- **В профиль врача:** откройте его карточку и добавьте строку в «Видео врача: Reels, ссылки и файлы».
- Укажите заголовок и выберите один источник: ссылка на публичный ролик или файл MP4 / WebM до 16 МБ. Для вертикального файла поставьте формат 9:16. Загруженные файлы доступны публике по прямой ссылке; для Reels посетители также могут открыть оригинал в Instagram.
- Переключите язык в админке, чтобы заполнить заголовок видео для нужной версии сайта.
